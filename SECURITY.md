# Security Policy

## Scope

This policy covers security issues in the hotel-software project and its documented setup. Only test systems and data you own or have explicit permission to assess.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately to the repository owner through GitHub's private contact options or a GitHub Security Advisory if enabled. Include the affected commit or version, steps to reproduce, expected and actual behavior, and relevant logs. Remove credentials, tokens, personal information, and other sensitive data from reports.

Please do not publish exploit details or sensitive information publicly before the issue has been reviewed.

## Supported Versions

No formal supported-version policy is currently published. Security fixes are handled on a best-effort basis.

## Safe Testing

Use a local test environment where possible. Avoid destructive testing, denial-of-service activity, accessing other users' data, or testing outside the scope of your authorization.
